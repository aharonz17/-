## התמונה הגדולה — שרשרת אחת

```
שעון נוכחות ──► מערכת שכר (חילן / מלם / מיכפל / שיקלולית ...)
                   │
                   ├─► תלוש שכר לעובד (פורטל / אפליקציה / PDF)
                   ├─► קובץ מס"ב ──► בנק המעסיק ──► חשבון העובד: שורת "משכורת" (עד ה-9 בחודש)
                   ├─► ממשק אחיד (XML) ──► קופות פנסיה / השתלמות
                   ├─► טופס 102 חודשי ──► מס הכנסה + ביטוח לאומי
                   └─► 126 שנתי למעסיק / 106 שנתי לעובד
```

**החיבור הקריטי:** `נטו לתשלום` בתלוש = הסכום שנכנס בשורת המשכורת בעו"ש. התאמה: סכום זהה, תאריך בחלון 1 עד 10 לחודש שאחרי חודש השכר, ושם מעסיק או לשכת שכר בתיאור. מקרי קצה: תשלום מפוצל, מקדמות, ולשכת שכר שמופיעה במקום המעסיק (פירוט במסמך 3).

## תובנות שחשוב לזכור

1. **אין תקן לאומי לקודי שכר.** כל מעסיק או מערכת מגדירים קודים משלהם. זיהוי רכיבים צריך להתבסס על תיאור הרכיב ולא על מספר הקוד.
2. **כל התלושים בנויים מאותם בלוקים** (בגלל סעיף 24 לחוק הגנת השכר): פרטי מעסיק ועובד, תשלומים, ניכויי חובה, ניכויי רשות, הפרשות מעסיק, נתוני מס, יתרות, מצטבר, וסיכום. בכך אפשר לבנות מודל נתונים אחיד (ראה "תלוש קנוני" במסמך 2).
3. **קבוצות בנקים חולקות מערכות:** הבינלאומי, אוצר החייל, מסד ופאג"י (מת"ף); דיסקונט ומרכנתיל; מזרחי ויהב. לכן מספיק פענוח אחד לכל קבוצה.
4. **קודי בנק יעברו מ-2 ל-3 ספרות** (הודעת בנק ישראל מינואר 2026). יש לשמור את קוד הבנק כמחרוזת.
5. **חיוב כרטיס אשראי בעו"ש הוא סכום מרוכז.** בניתוח הוצאות יש לסמן אותו כהעברה פנימית, אחרת ההוצאות נספרות פעמיים.
6. **בנקאות פתוחה (הוראה 368, מבוססת Berlin Group)** היא הדרך הרשמית למשיכת תנועות. חלופות: קבצי ייצוא (Excel/CSV, לעיתים בקידוד windows-1255), או ספריות scraping כמו israeli-bank-scrapers.

## מודל נתונים מאוחד (הצעה)

```
Employee      { id_number, name, bank_code(str), branch, account, tax_points, start_date }
Payslip       { employee, employer_tax_file, period(YYYY-MM), system_vendor,
                gross, taxable_income, income_tax, bl, health, pension_employee,
                other_deductions, net, net_to_pay, lines[] }
PayslipLine   { code, description, category(earning|mandatory|voluntary|employer|imputed),
                qty, rate, amount }
BankTxn       { bank_code(str), account, booking_date, value_date, description,
                reference, debit, credit, balance, category }
Match         { payslip_id, bank_txn_id, confidence, rule }
```

## מה עוד פתוח לאימות (ריכוז)

- **שכר:** שיעורי ביטוח לאומי של המעסיק ל-2026; נקודות זיכוי לילדים בגילי 0–3 ו-6–17 (תיקון 2024); הנחות שווי לרכב היברידי וחשמלי; תקרות לזקיפת פיצויים והפרשות מעסיק; תקרת דמי לידה.
- **מערכות:** פריסת התלוש המדויקת במיכפל, בשיקלולית, בריווחית ובסינריון (מומלץ להשיג תלושים אמיתיים לדוגמה); מספרי הלקוחות של חילן ומלם.
- **בנקים:** קוד הבנק של esh; אורכי מספרי חשבון לכל בנק; מחרוזות התיאור המדויקות בכל בנק; אורך הרשומה בקובץ מס"ב.

**צעד מומלץ הבא:** לאסוף כמה תלושים ודפי חשבון אמיתיים (אפשר מושחרים) מכמה מערכות ובנקים, ולאמת מולם את המבנים שתוארו.
