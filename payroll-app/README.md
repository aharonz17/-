# מערכת שכר, תלושים ועו״ש

מערכת ישראלית לחישוב שכר מלא, הפקת תלושי שכר, תשלומים ודפי חשבון בנק. הנתונים נשמרים במסד נתונים מקומי ועצמאי (קובץ SQLite יחיד). המערכת **לא משדרת דבר** לרשויות, לקופות או לבנקים: הדיווחים וקובץ מס״ב הם קבצים להורדה בלבד.

## הפעלה

**דרישה:** [Node.js](https://nodejs.org) גרסה 22.13 ומעלה (מומלץ LTS). מסד הנתונים מובנה ב-Node (`node:sqlite`), כך שאין רכיבים שצריך לקמפל.

- **Windows:** לחיצה כפולה על `start.bat`
- **Mac/Linux:** `./start.sh`
- **ידנית:**
  ```
  npm install
  npm run build
  npm start
  ```

אחרי ההפעלה פותחים את http://localhost:3000.

**בכניסה הראשונה** יוצרים משתמש וסיסמה (לפחות 8 תווים). הם ישמשו לכל כניסה מאז והלאה.

**נתוני הדגמה:** `npm run seed` יוצר מעסיק, שני עובדים, שלושה חודשי שכר, חשבונות בנק בהדמיה והתאמות.

**שכחתם סיסמה:**
```
npm run create-user -- admin NewPassword123
```

### אם ההפעלה נכשלה
- `'next' is not recognized`: ההתקנה הקודמת לא הסתיימה. מוחקים את התיקייה `node_modules` ומפעילים שוב את `start.bat`.
- אחרי עדכון גרסה של המערכת: מוחקים את התיקייה `.next`, ו-`start.bat` יבנה מחדש.

### איפה הנתונים
- המסד נשמר בקובץ `data/payroll.db`. כדאי לגבות אותו (מספיק להעתיק את הקובץ כשהמערכת סגורה).
- אפשר לשנות את המיקום עם משתנה הסביבה `DATABASE_PATH`.
- הקובץ לא מוצפן. שמרו אותו על מחשב מוגן, כי יש בו ת״ז, שכר ופרטי בנק.

## מה המערכת עושה

| תחום | יכולות |
|---|---|
| **עובדים** | פרטים אישיים, העסקה (חודשי/שעתי/יומי, היקף משרה), פנסיה, קרן השתלמות, רכב, טלפון, נסיעות, הבראה, רכיבים קבועים, יתרות פתיחה |
| **מס** | פרופיל מס לכל שנה. **נקודות הזיכוי מחושבות מהעובדות:** ילדים לפי גיל, חייל משוחרר, תואר, עולה חדש, לוחם מילואים, הורה יחיד. בנוסף: יישוב מזכה ותיאום מס |
| **חישוב שכר** | ברוטו; שעות נוספות 125/150/175/200%; מחלה 0/50/100%; היעדרויות; חודש חלקי; שווי רכב וטלפון; מס הכנסה (חודשי, מצטבר, מרבי או לפי תיאום); זיכוי פנסיה 45א; ביטוח לאומי ומס בריאות; פנסיה; פיצויים; קרן השתלמות וזקיפה מעל התקרה; ניכויי רשות; נטו; עלות מעסיק; צבירת חופשה ומחלה; בדיקת שכר מינימום |
| **"כיצד חושב?"** | לכל מספר מוצגת הנוסחה והכלל שהפעיל אותו (כולל גרסת הכלל) |
| **הרצת שכר** | טיוטה ← חישוב ← אישור ונעילה ← תלוש Snapshot שלא משתנה, עם חתימת אימות. ביטול שומר את התלושים בסטטוס "בוטל" |
| **תלוש PDF** | בפורמט ישראלי מקצועי, עם כל שדות החובה לפי סעיף 24 לחוק הגנת השכר |
| **תשלומים** | נוצרים אוטומטית באישור ההרצה; קובץ מס״ב ו-CSV להורדה |
| **בנק** | חשבונות אמיתיים וחשבונות הדמיה; דף חשבון עם יתרת פתיחה, יתרה מתגלגלת ויתרת סגירה; בדיקת התאמה שורה-שורה; סיווג אוטומטי של תנועות |
| **ייבוא** | Excel (xlsx), CSV (UTF-8 / windows-1255) וקובצי "xls" מהבנק (טבלת HTML). כולל זיהוי כותרות, מיפוי עמודות, תצוגה מקדימה ושמירת תבנית מיפוי |
| **התאמות** | שיוך תשלום שכר לתנועת זכות בבנק, עם ציון ונימוקים |
| **דוחות** | סיכום 102 חודשי; סיכום שנתי ו-CSV (בסיס ל-126); ריכוז שנתי לעובד (בסיס ל-106); גמר חשבון (פיצויים, הודעה מוקדמת, פדיון חופשה) |
| **כללים** | כל ערך (מדרגות, ספים, שיעורים) נשמר כגרסה עם תאריכי תוקף ומקור. שנה חדשה = גרסה חדשה מהממשק, בלי לשנות קוד |
| **יומן** | כל שינוי משמעותי נרשם, ואין מחיקת היסטוריה |

## חשוב לפני שימוש בשכר אמיתי

- **כללים לא מאומתים:** חלק מהכללים מסומנים "לא מאומת", והמערכת מציגה אזהרה בכל חישוב שמשתמש בהם. לפני שמשלמים שכר לעובדים אמיתיים, אמתו אותם במסך **כללי חישוב** מול רשות המסים, ביטוח לאומי וכל-זכות, או עם יועץ שכר. הכללים הלא מאומתים:
  - שיעורי ביטוח לאומי למעסיק ל-2026
  - נקודות זיכוי לילדים בגילים שאינם 4–5
  - הפחתות רכב ירוק ל-2026
  - טבלת החופשה לוותק 11–14
- **מה לא ממודל:**
  - שיעורי ביטוח לאומי מיוחדים לנוער ולגיל פרישה (המערכת מתריעה)
  - הסכמים קיבוציים וצווי הרחבה ענפיים
  - נקודת הזיכוי להורים לילדים 6–17 במבחן הכנסה (אפשר להוסיף ידנית בפרופיל המס)
- **קובץ מס״ב:** המבנה לא אומת מול המפרט הרשמי של מס״ב. בדקו אותו מול הבנק לפני העלאה.
- **דמי חופשה לעובד שעתי:** מחושבים לפי ערך יום, ולא לפי "שכר יומי ממוצע" שבחוק.

```

src/server/     מסד נתונים, שירותים, התחברות, יומן
src/app/        מסכים (Next.js)

tests/          בדיקות
```
